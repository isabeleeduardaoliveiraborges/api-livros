🔴🟣 API — Atividade do 3º Ano | ETEC
Projeto desenvolvido para a atividade do 3º bimestre do 3º ano do Ensino Médio Técnico da ETEC.

Uma API REST desenvolvida ao longo de quatro aulas, com o objetivo de colocar em prática os conhecimentos adquiridos durante o curso, trabalhando conceitos de desenvolvimento de APIs, requisições HTTP, rotas, organização de código e manipulação de dados.

🔴 Sobre o Projeto
Este projeto faz parte de uma atividade do 3º bimestre, dividida em 4 aulas, onde cada etapa contribui para a construção e evolução da API.

A proposta é desenvolver uma aplicação capaz de disponibilizar e manipular informações através de endpoints, permitindo que outras aplicações possam consumir os dados fornecidos pela API.

🟣 Objetivos
Desenvolver uma API REST.
Praticar a criação e organização de rotas.
Trabalhar com métodos HTTP.
Realizar operações de consulta, criação, atualização e exclusão de dados.
Compreender o funcionamento de uma API e sua comunicação com outras aplicações.
Aplicar conceitos aprendidos durante as aulas.
📚 Desenvolvimento por Aulas
O projeto foi dividido em quatro etapas:

🔴 Aula 1 — Estrutura Inicial
Criação do projeto.
Configuração do ambiente.
Organização inicial das pastas.
Criação da estrutura básica da API.
🟣 Aula 2 — Rotas e Endpoints
Criação dos endpoints.
Utilização dos métodos HTTP.
Implementação das primeiras funcionalidades.
Testes das requisições.
🔴 Aula 3 — Manipulação de Dados
Implementação das operações com os dados.
Criação, consulta, alteração e exclusão de informações.
Tratamento das requisições.
🟣 Aula 4 — Finalização e Testes
Revisão do código.
Correção de erros.
Testes dos endpoints.
Organização final do projeto.
Documentação da API.

🚀 Como Executar o Projeto
1. Clone o repositório
git clone URL_DO_REPOSITORIO

2. Entre na pasta
cd nome-do-projeto

3. Instale as dependências
npm install

4. Execute a aplicação
npm start

A API estará disponível localmente na porta configurada pelo projeto.

Exemplo:

http://localhost:3000
